Square segmented control; the pressed option inverts to midnight. For Yes / Partly / No answers and 1–5 scales.

```jsx
<Segmented options={["Yes","Partly","No"]} value={v} onChange={setV} />
```

Styling comes from the brand classes in `styles.css` (css/components.css, css/chrome.css). Square corners, 1px rules, no shadows; one orange element per view.
