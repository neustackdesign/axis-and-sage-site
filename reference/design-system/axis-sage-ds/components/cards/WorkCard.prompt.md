Work-index cell (place in a .work-grid): sector, name, one-line result, role and action chips.

```jsx
<div className="work-grid"><WorkCard name="Mular" sector="Payments" roles={["FOUNDED"]} actions={["Customers buy"]} line="$2.1M+ processed…" /></div>
```

Styling comes from the brand classes in `styles.css` (css/components.css, css/chrome.css). Square corners, 1px rules, no shadows; one orange element per view.
