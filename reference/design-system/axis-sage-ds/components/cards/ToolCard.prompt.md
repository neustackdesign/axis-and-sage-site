Sage library card for a free tool: kind label, badge chip, glyph, title, one line and a link. Place in .tool-grid.

```jsx
<ToolCard kind="SCORECARD · 6 MIN" title="Conversion Scorecard" line="Who isn't acting…" glyph="moment" cta="Take the Scorecard" />
```

Styling comes from the brand classes in `styles.css` (css/components.css, css/chrome.css). Square corners, 1px rules, no shadows; one orange element per view.
