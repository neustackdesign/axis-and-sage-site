Design system · v3 · August 2026

tomiwao.com design system

The reference for every page on the site. Two typefaces (Helvetica + Geist Mono), six warm neutrals, a Substack-style column model, and a handful of repeating components. When in doubt, remove.

Principles

1. Restraint is the aesthetic. No gradients, no color accents, no chips, no icons for their own sake. Hierarchy comes from type scale, weight, case, and hairline rules only.

2. Two voices. Helvetica carries all reading: headlines, body, descriptions. Geist Mono, almost always uppercase with 0.08em tracking, carries all apparatus: nav links, kickers, dates, tags, captions, meta labels, section labels. If text is about the content rather than the content itself, it is mono caps.

3. One accent: black. Section-opening rules are 1px ink (#1a1915); internal dividers 1px parchment (#e3dfd3). That two-weight rule system carries all structure.

4. The column model is the layout. All flowing text lives in one uniform 680px column, centered. Wide elements (images, stat blocks, multi-column grids) break out to 960px, also centered. Nothing is left-anchored to the page edge.

Layout: three widths, all centered

shell · max-width 1200px · padding 0 24px · nav + footer
breakout · 960px · images, stats, grids
prose · 680px · all flowing text

Shell: max-width:1200px; margin:0 auto; padding:0 24px 96px. Prose blocks (h1 headers, h2, p, ul, list rows, tags, next-links): max-width:680px; margin-inline:auto, text left-aligned within the column. Breakout blocks (figures, stat blocks, contact/services grids, home sections): max-width:960px; margin-inline:auto. The home page is the one exception: its hero and sections sit at 960px because it is a landing surface, not an article.

Vertical rhythm: 140px above footers, 100–120px between home sections, 64–72px above h2, 26px padding in list rows, 16–18px between paragraphs. Sibling groups always use flex/grid + gap, never margins between inline siblings.

Typography

Two families. 'Helvetica Neue', Helvetica, Arial for all reading text, sentence case. 'Geist Mono' (Google Fonts, 400/500) for all apparatus, usually UPPERCASE with letter-spacing:0.08em. No serif, no italic except book titles, no third face. Display letter-spacing -0.01em to -0.02em.

Components

Navigation

Full shell width. Name (15px Helvetica medium, lowercase, no underline) left; mono-caps links (12px, #5d5a50, 24px gap) right. No active states, no logo mark. Case pages add a mono-caps “← work” crumb 48px below.

List row (work index, experience, essays)

Lives in the 680px column, opened by a 1px ink rule. Grid: content 1fr + right-aligned mono meta auto; 1px parchment bottom border. Titles Helvetica 700 24px; descriptions 15px #5d5a50. Whole row is the link where applicable.

Stat block

960px breakout. Grid auto-fit minmax(180px,1fr); ink rule above, parchment below. Number Helvetica 700 38px; label Geist Mono 12px #5d5a50. Only for evidenced figures.

Case-study header

680px column: mono-caps kicker → Helvetica 700 h1 → 19px lede → meta row (mono-caps 11px label over 15px Helvetica value) under a parchment rule.

Figure

960px breakout. 1px #e3dfd3 border, square corners, Geist Mono 12px #8a8678 caption. No shadows, no rounded corners anywhere on the site.

Tags

680px column. Geist Mono 11px uppercase, ls 0.06em, #5d5a50, 1px #d8d4c6 border, 6px 12px padding, square corners, 10px gap.

Footer

1px ink rule, then mono-caps utility links at shell width. The home footer adds a large Helvetica 700 closing statement with an inline underlined CTA at 960px.

Voice

Lowercase in the nav wordmark; UPPERCASE only via mono apparatus; sentence case everywhere else. Short declarative sentences. Claims carry evidence and sources; self-critique is part of the voice. No exclamation marks, no emoji, at most one em-dash per page.

Label + content row (home only)

960px breakout, unique to the home page as a landing surface. Grid minmax(0,1fr) minmax(0,1.6fr), 48px gap. Left column: mono-caps section label (12px, #5d5a50, weight 400, no bottom rule) acting as the heading — this replaces the Helvetica 700 24px h2 used everywhere else. Right column holds body text or a list row group. Do not use this pattern inside case studies or the 680px prose column.

Known drift to fix: home page work-item descriptions omit the max-width:64ch the work index applies to the same rows — add it for wrap consistency. The home nav logo links to href="#" instead of the file path used on every other page — fix to a real self-link.
